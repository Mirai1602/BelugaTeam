# BelugaCalc

Estructura:

- `main.py`: punto de entrada.
- `ui/main_windown.py`: menú principal.
- `ui/basica_window.py`: suma, resta y multiplicación.
- `ui/avanzada_window.py`: Gauss, Gauss-Jordan, reducción de pivotes y conversiones.
- `core/operaciones.py`: lógica matemática.
- `core/conversiones.py`: conversiones numéricas.
- `core/matriz.py`: clase Matriz original.
- `core/utils.py`: funciones auxiliares.
- `controllers/main_controller.py`: controlador anterior, conservado por compatibilidad.
- assets: Contiene pantallas gráficas de UI

Para ejecutar:

```bash
python main.py
```

Requiere PyQt6.
